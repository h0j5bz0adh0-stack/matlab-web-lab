# 💻 سامانه آزمایشگاه تحت وب متلب و پنل نظارت استاد (MATLAB & Octave Web Lab)

محیط ابری و یکپارچه برای اجرای کدهای متلب/اکتاو، شبیه‌سازی و رسم نمودارها ویژه دانشجویان درس مهندسی پزشکی، به همراه پنل مانیتورینگ زنده برای استاد.

## 🌟 قابلیت‌ها:
- **ویرایشگر کد تعاملی:** هایلایت کدهای متلب، نمونه‌کدهای آماده مهندسی پزشکی (ECG، FFT، فیلتر باترورث).
- **موتور اکتاو امن:** اجرای بلادرنگ محاسبات ماتریسی با پشتیبانی از رسم پلات و نمودار خودکار.
- **پنل نظارت استاد (`/admin`):** ورود رمزدار، مشاهده کدهای ارسال‌شده، نام و شماره دانشجویی، زمان اجرا و امکان خروجی کامل JSON.
- **تایم‌اوت و مدیریت منابع:** جلوگیری از قفل شدن سرور با سقف زمان اجرا و اجرای تک‌تردی.
